# ⚡ Sistema de Agendamento para Eletricista

Site institucional responsivo com sistema integrado de agendamento de serviços elétricos e painel administrativo para gerenciamento de clientes.

## 🚀 Funcionalidades
- **Landing Page Responsiva:** Design moderno com foco em conversão, apresentação de serviços, alerta de segurança elétrica e mapa de localização integrado (Londrina/PR).
- **Agendamento Online:** Formulário com validação de datas (bloqueio de datas passadas) conectado ao banco de dados MySQL.
- **Painel Administrativo (`admin.php`):** Visualização em tempo real dos agendamentos solicitados (nome, WhatsApp, data, horário e descrição do problema) com opção de exclusão.

## 🛠️ Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3 (Layout responsivo e limpo), Google Fonts (Poppins) e Google Maps Embed.
- **Back-end:** PHP.
- **Banco de Dados:** MySQL.
